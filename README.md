# Redi

> 装在 [MCphone](https://github.com/november521/mcphone) 手机里的 AI 助手扩展模组
> Minecraft 1.21.1 · NeoForge 21.1.249

一款基于 MCphone 实现的扩展 App,给 MC 装上一个超强的 Agent 工具——
在游戏手机里装一个真正能干活的 AI 助手:用自然语言描述任务,Redi 自己规划步骤,
通过内置工具读取游戏内存、查阅模组手册、合成物品、执行指令——像玩家本人一样把事情做完。
只读代码与资源,绝不修改游戏文件。

## 特性

- **通用 Agent**:不是写死的指令集。任意自然语言任务,模型自主规划、调用工具、自我纠错
- **分层取证**:按 内存实时读取 → 本地文件/手册 → 联网搜索 的优先级自动取证,严禁跳层
- **内存树导航**:注册表、背包、配方、类结构以树形组织,沿分支逐层下钻,精准定位
- **模组手册直读**:自动解析帕秋莉(Patchouli)手册;祭坛召唤、献祭、仪式等
  非工作台获取方式按手册原文以文字描述,不硬套合成网格
- **插件化架构**:cordis 风格(Context / 可回滚副作用 / 作用域隔离),扩展功能即添加插件
- **虚拟工作台 / 熔炉**:无需摆放方块,材料真实消耗,成品由玩家自取
- **过程可见**:实时思考面板(可展开完整过程)、工具调用中文标注、会话历史与上下文恢复
- **多服务商**:DeepSeek / 智谱 GLM / Kimi / 通义千问 / 硅基流动 / OpenAI / 自定义 OpenAI 兼容接口

## 安装

1. 安装 NeoForge 1.21.1 与 MCphone 1.8.20+
2. 将 `release/Redi-1.21.1-1.0.0.jar` 放入 `mods/` 文件夹
3. 启动游戏,打开手机中的 **Redi** → 右上角 ⚙ 进入设置:
   - 选择服务商预设 → 填入 API Key → 点「获取模型」选择模型 → 测试连接

## 使用

| 示例 | Redi 会做的事 |
|---|---|
| 「诡厄巫法这模组怎么玩?」 | 读模组速览与帕秋莉手册,给出玩法讲解 |
| 「我副手拿的是什么?怎么合成?」 | 读背包识别物品,给出属性与配方网格 |
| 「帮我用 8 个石头合成熔炉」 | 校验配方、消耗背包材料、成品入包 |
| 「给全服发个集合消息」 | 以玩家身份发送聊天消息 |

- 输入框左侧「思考:低/中/高」切换推理强度;任务运行中点 **■** 随时停止
- 点击“思考中…”可展开完整的思考与工具调用过程
- 按 **ESC** → 左上角「Agent 插件」查看已装载插件及其工具
- 手机界面右上角「历史」查看历史会话,「新对话」清空上下文

## 开发

```bash
./gradlew build      # 构建 jar(输出 build/libs/)
./gradlew runClient  # 开发运行(需 Java 21)
```
